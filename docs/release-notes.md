## 这是桌面安装包，不是系统精简包

本分支基于 Gathin23/cleanyourtv（原 tv-vibehack）的 launcher 改造，保留原作者署名和 MIT 许可证。上游 ADB 工具与精简示例仍在源码中供参考，**安装这个 APK 不会运行它们**。

功能：统一显示电视应用、普通应用和小米应用中心；自动用原图标合成横幅，完整等比显示并用边缘颜色补齐；小米 Novatek 信号源名称适配；长按应用设置常用位置并持久保存。

此前现场停用广告及统计组件是单独的 ADB 操作，不包含在本 APK。此安装包不会自动去除开机广告或视频应用内部广告，也不聚合观看历史。保留原桌面和核心服务以便恢复。

## 安装

下载附件中 `.apk` 文件，传到电视，用文件管理器打开安装；按电视提示允许该来源安装。Android 8.0+ 可尝试，实机测试为 MiTV-NSOP0 / Android 9，其他固件兼容性未逐一验证。安装后打开试用，系统支持时选择为默认桌面；某些小米固件需要 ADB 设置主页键。

完整安装、升级和恢复步骤：[中文说明](https://github.com/Gitawake/tv-vibehack-xiaomi/blob/xiaomi-android9/README.zh-CN.md)。

APK 由本次 GitHub Actions 工作流编译并使用固定发布密钥签名。可用 SHA256SUMS 检查下载完整性；证书信息见 signing-certificate.txt。调试版或上游版可能签名不同，需先切回原桌面并卸载旧版后再安装，旧版桌面偏好设置会随卸载清除。后续同签名发布版本可直接覆盖升级。
