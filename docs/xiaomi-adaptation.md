# 小米 Android 9 适配记录

## 应用发现

中国版小米固件的部分系统应用不声明 `LEANBACK_LAUNCHER`。应用中心使用 `android.intent.category.APPSTORE_LAUNCHER`。本分支扫描上述类型及普通 `LAUNCHER`，以 activity component 去重，直接调用应用原有入口，无需额外快捷方式 APK。

## 图片策略

横幅最小尺寸为 240×100，宽高比为 1.45～2.15。否则使用应用原图标合成 480×270 图片，等比完整显示；左右空白由对应边缘像素横向延展补齐。透明像素先合成到不透明边缘采样色，无可采样颜色时使用深蓝灰底色。没有模糊和图片内文字，也不会裁切方形图标。

## 信号源

通用名称优先使用 `TvInputInfo.loadCustomLabel()`。对已验证的 Novatek HDMI1/2/3 和 CVBS 服务包映射为 HDMI1/2/3、AV，其他平台保留系统标签。显示标签不改变切换目标的 input ID。

## 精简与权限

本次设备上以 `pm disable-user --user 0` 停用的广告与统计包：

- `com.miui.systemAdSolution`
- `com.miui.analytics`
- `com.miui.tv.analytics`
- `com.xiaomi.statistic`

这些操作未证明能够消除开机广告或视频广告。该设备的桌面还会加载内嵌广告插件；普通 ADB 无权单独停用其部分组件。开机广告最终由用户联系厂家取消，本项目不自动执行该流程。

`com.mitv.care` 在后续整理前已处于停用状态，不纳入本分支安装动作。

保留小米原桌面、应用中心、系统设置、系统更新、播放及解码服务、遥控器、蓝牙、语音、投屏和互联服务。精简清单是现场记录，不是跨机型安全保证；安装脚本不执行这些停用命令。

## 长辈模式

在该设备上通过小米界面切换后，系统 `user_mode` 记录值为 2。桌面进程重新启动后模式记录仍保留。未找到禁止退出的密码锁；这不是可跨型号硬编码的设置协议。替换默认桌面不删除小米桌面的模式配置。
